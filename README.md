# 🎯 What is OOP Using Java?

A **production-quality Object-Oriented Programming repository** built using Java, combining academic rigor with software engineering best practices.

Every module includes:

- ✅ Clean and modular Java code
- ✅ Industry-standard project structure
- ✅ OOP concepts explained with practical examples
- ✅ JUnit 5 test suites
- ✅ UML diagrams and architecture notes
- ✅ Maven build automation
- ✅ Interview-focused implementations
- ✅ Design Patterns and SOLID principles
- ✅ Documentation and learning resources

# 🚀 Quick Start

```bash
# 1. Clone the repository
git clone https://github.com/rahulkp-ai/oop-using-java.git
cd oop-using-java

# 2. Auto setup (recommended)
chmod +x setup.sh && ./setup.sh

# 3. Build project
mvn clean install

# 4. Run all tests
mvn test

# 5. Generate reports
mvn site

# 6. Run examples
mvn exec:java
```
